# VIZDEV website

Responsive static website for VIZDEV, an independent digital product studio. Built with HTML, CSS and JavaScript; no build step is required.

## Publish with GitHub Pages

1. Repository: `VinayakGS-22/vizdev-website` (private).
2. Open **Settings → Pages** and confirm GitHub Pages is available for this private repository under your GitHub plan.
3. This repository includes a GitHub Actions workflow to deploy the site. In **Settings → Pages**, choose **GitHub Actions** as the Build and deployment source if prompted.
4. Check the **Actions** tab for the deployment workflow and its published URL.
5. The usual project URL is `https://vinayakgs-22.github.io/vizdev-website/`.

The repository source stays private; the published Pages website is public. Private-repository Pages requires an eligible paid GitHub plan. If Pages is unavailable on your plan, upgrade or use a public deployment repository only if you are comfortable exposing its source.
